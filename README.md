# ⚡ AI 获客工作台

单人本机运行的获客与跟进工作台 · 0.5.0 / schema 1.3 · 人工审核与对外联系。

网页与 MCP 共用同一业务服务。AI 只做研究与拟稿；审核、联系、报价全部由人完成，不自动发送客户消息、不代点审核、不自动改采购阶段、不自动报价。业务状态只保留一份，不建第二客户库。

数据仅保存在本机，应用只监听 `127.0.0.1`。无注册，无第三方统计、广告或崩溃上报 SDK；应用密钥由系统钥匙串管理，不写入数据库或文件。

## 打开

在本目录运行 `./启动工作台.command`，然后打开 <http://127.0.0.1:8765/>。已启动时脚本识别本应用并显示入口；端口被其他应用占用时不会强制停止它。

停止：关闭运行终端或按 `Ctrl+C`。电脑休眠期间不执行任务；重新打开可见逾期待办。
