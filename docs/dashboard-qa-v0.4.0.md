# 浅色主题验收清单

每个视图分别在 1440 与 390 宽度、深色与浅色两种主题下检查。

| 视图 | 重点 |
|---|---|
| 获客总览 | KPI 数值、漏斗、渠道环图、趋势折线、Hero 标题 |
| 线索池 | 表头、行 hover、状态标签、分页、筛选按钮 |
| 线索详情 | 证据卡、时间线、跟进按钮 |
| 客户项目 | 项目卡标题、阶段条、缺失项提示 |
| 采购机会 | 看板列、机会卡、横向滚动阴影 |
| 跟进日程 | 周视图、今日重点、逾期标记 |
| 转化报告 | 报告卡、指标条、空态 |
| 团队与设置 | 表单、开关、危险区、帮助卡 |
| 设计基线 | 色板、按钮状态、字段状态（仅内部预览） |
| 覆盖层 | 记录抽屉、跟进表单、导出弹窗、命令面板、Toast |

逐项确认：

- [ ] 无白底白字、无深底深字。
- [ ] 正文对比度 ≥ 4.5:1，大字号 ≥ 3:1。
- [ ] 图表网格与坐标轴可读，系列色不变。
- [ ] 抽屉遮罩为暖棕，不是纯黑。
- [ ] 表单聚焦环可见，`option` 背景为白色。
- [ ] 移动 dock 不遮挡内容，阴影向上。
- [ ] 切换主题不刷新页面，刷新后保持。
- [ ] 首屏无主题闪烁。
- [ ] 控制台 0 错误，无横向溢出。
- [ ] `prefers-reduced-motion` 下切换无动画问题。
