# 京小电获客工作台｜深浅色主题方案

版本：`v0.4.1-theme`　基础设计：`v0.4.0`　日期：2026-11-24

## 1. 定位

深色是默认主题，浅色是“暖纸感”工作模式：米白底、白色玻璃卡、暖橙强调保持不变。浅色不做反相，不把玻璃换成实心白块，也不改布局、圆角、字号和栅格。

## 2. 色彩令牌

| 令牌 | 深色 | 浅色 |
|---|---|---|
| `--bg` | `#1A1A1A` | `#F4F1EC` |
| `--main` | `#2D2D2D` | `#FFFFFF` |
| `--glass-1` | 白 7.5% | 白 82% |
| `--glass-2` | 白 6% | 白 66% |
| `--glass-3` | 白 4% | 白 48% |
| `--border` | 白 10% | 暖黑 11% |
| `--border-bright` | 白 30% | 暖黑 22% |
| `--text` | `#FFFFFF` | `#1B1712` |
| `--text-2` | `#CCCCCC` | `#4B443C` |
| `--text-3` | `#999999` | `#857A6E` |
| `--orange` | `#FF6B35` | `#E2571F` |
| `--orange-light` | `#FFB347` | `#B8430F` |
| `--gold` | `#FFD700` | `#C08A00` |

浅色下橙色压暗一档，保证白底上的小字号可读；深色下保持原品牌亮橙。

## 3. 组件规则

- 外壳：浅色为白色半透明玻璃，阴影改为暖棕而非纯黑，避免发灰。
- 侧栏 / 顶栏：白 70%–86% 玻璃，边框用暖黑 8%–11%。
- 卡片：白色玻璃叠加一层顶部高光，阴影 `0 8px 28px rgba(72,54,34,0.10)`。
- Hero：保留人物摄影，左侧改暖白渐变；标题用主文字色，不再用纯白。
- 图表：网格线与坐标轴跟随文字色，系列色（橙/金/蓝/绿）保持不变。
- 覆盖层：抽屉与弹窗用 `#FFFDFA`，遮罩改为暖棕 38%，不再用纯黑。
- 表单：白底、暖黑边框、橙色聚焦环；`option` 背景显式设为白色。
- 移动端 dock：白色 92% 玻璃，阴影向上。

## 4. 切换交互

| 项 | 规则 |
|---|---|
| 位置 | 顶栏右侧，通知按钮之前 |
| 形态 | 复用 `.icon-button`，太阳/月亮图标 |
| 状态 | `aria-pressed` 标识当前是否为浅色 |
| 持久化 | `localStorage["jxd-theme"]`，值 `dark` / `light` |
| 首屏 | `<head>` 内联脚本先写入 `data-theme`，避免闪白 |
| 默认 | 深色；不默认跟随系统，避免首访被系统设置改变 |
| 跨标签 | 监听 `storage` 事件同步 |

`theme.js` 已实现上述行为，按钮在 `.topbar-right` 自动挂载，不需要改模板结构。

## 5. 实现顺序

1. 把 `theme-light.css` 放在 `dashboard_v2.css` 之后加载。
2. 在 `<head>` 加入内联主题初始化脚本，再加载样式。
3. 在 `</body>` 前加载 `theme.js`。
4. 按 `PATCH.md` 的三段代码接入。
5. 跑 `QA-CHECKLIST.md` 的十视图验收。

## 6. 必改点

现有 `styles.css` 有 352 处 `rgba(255,255,255,…)` 与 162 处十六进制色值，仅覆盖变量不够。参考实现采用“变量覆盖 + 组件定向覆盖”，不改原文件；后续维护时优先把新增颜色写进令牌，不再直接写死。

重点风险：

- `color: #fff` 的标题与数值在浅色下会消失，已在参考实现中逐项覆盖。
- `.circle-arrow`、`.filter-count` 等小控件需单独确认对比度。
- 图表 SVG 内的渐变写死金色与橙色，浅色下可继续使用。

## 7. 验收

十视图 × 1440 / 390 × 深浅两主题，全部满足：

- 无白底白字、无深底深字。
- 正文对比度 ≥ 4.5:1，大字号 ≥ 3:1。
- 图表网格、坐标轴、图例可读。
- 切换后不重载页面，状态保留。
- 首屏无主题闪烁。
- 控制台 0 错误。

## 8. 已知限制

`theme-light.css` 是第一阶段参考实现，覆盖外壳、总览、卡片、列表、表单、覆盖层和移动 dock；本环境未能启动浏览器做像素验收，视觉结果需施工窗口按 `QA-CHECKLIST.md` 逐页确认后再定版。设置页、设计基线页和部分详情组件的浅色细节可能仍需微调。
