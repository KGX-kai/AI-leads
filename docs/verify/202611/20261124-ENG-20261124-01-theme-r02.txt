- /static/theme-init.js 为同步外部脚本，位于样式之前。

- /static/dashboard_v2.js 后加载 /static/theme.js，两者均有 defer。
- /dashboard-v2 只有三个外链 script：
  /static/theme-init.js
  /static/dashboard_v2.js
  /static/theme.js
- HTML 无内联 script 正文；主题初始化未触发 script-src CSP。
- 三个主题资源均返回 HTTP 200。

- lead-table -> .data-table

  .funnel-row > strong、.project-card h3、.opp-card h4、
  .agenda-copy strong、.quality-row strong。

  浅色逾期时间使用 var(--danger)，实测为 #B3362A。
